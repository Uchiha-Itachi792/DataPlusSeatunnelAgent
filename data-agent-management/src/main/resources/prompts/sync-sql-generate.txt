# 编写要求

1. **方言**：严格使用 **MySQL** 语法，表名和列名用反引号转义（如 `order`）。
2. **语句类型**（按需组合，用分号 `;` 分隔多条语句）：
   - 若目标表**不存在**：先生成 `CREATE TABLE`，再生成 `INSERT INTO ... SELECT ...`（可含 JOIN/WHERE/GROUP BY/表达式）。
   - 若用户要求同步前清理目标表部分数据：生成 `DELETE FROM ... WHERE ...`。
   - 主同步语句：`INSERT INTO 目标表 (...) SELECT ... FROM ...`（可 JOIN 关联表、过滤、聚合、字段计算）。
3. **禁止**在脚本中使用：`DROP`、`TRUNCATE`、`ALTER USER`、注释（`--` 或 `/* */`）。
4. **输出格式**：仅输出 SQL 脚本本身，不要 markdown 代码块，不要额外说明文字。
5. **列映射**：INSERT 的目标列必须与 SELECT 列一一对应；复杂映射用表达式完成。
6. **安全**：不要 `SELECT *`，明确列出需要的列。
7. **关联过滤（重要）**：若用户按「商品名/用户名/分类名」等**源表中不存在的属性**过滤，必须通过外键 JOIN 关联表（如 `order_items.product_id = products.id`），在 `WHERE` 中写过滤条件；**禁止**忽略用户排除/过滤要求。
8. **示例**：排除商品名为 T恤衫 的明细：
   `INSERT INTO order_items_back (...) SELECT oi.... FROM order_items oi JOIN products p ON oi.product_id = p.id WHERE p.name <> 'T恤衫'`
