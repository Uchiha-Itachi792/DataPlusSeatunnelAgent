# 编写要求

1. **结构**：必须包含 `env`、`source`、`sink` 三个顶层块；需要字段转换、过滤、JOIN 时可增加 `transform` 块。
2. **Connector 限制（本阶段）**：source 与 sink 均使用 `Jdbc`，driver 固定为 `"com.mysql.cj.jdbc.Driver"`。
3. **连接信息占位符（必须）**：不得填写真实连接信息，必须使用以下占位符：
   - `url = "__JDBC_URL__"`
   - `user = "__JDBC_USER__"`
   - `password = "__JDBC_PASSWORD__"`
   - sink 的 `database = "__JDBC_DATABASE__"`
4. **复杂 SQL**：放在 `source.Jdbc.query` 或 `transform \{ Sql \{ query = "..." \} \}` 中；使用 MySQL 语法，表名/列名用反引号。
5. **环境**：默认 `env \{ parallelism = 1; job.mode = "BATCH" \}`；**禁止** `STREAMING` 模式。
6. **禁止**：Kafka、MySQL-CDC、Elasticsearch 等非 Jdbc connector；禁止 markdown 代码块；禁止注释（`#`、`//`）。
7. **列映射**：sink 需明确 `table = "目标表名"`；复杂映射通过 source query 或 transform 完成。
8. **关联过滤**：若用户按商品名/用户名等源表不存在的属性过滤，必须通过 JOIN 关联表并在 WHERE 中写条件。
9. **WHERE 强制**：用户提到「排除」「过滤」「不要」「仅」「只」等过滤语义时，`source.Jdbc.query` **必须**包含 `WHERE` 子句，不得仅写 JOIN 而无过滤条件。
10. **JOIN 完整性**：所有 relatedTables 必须在 query 内通过 JOIN 连接；过滤条件写在 WHERE，不要遗漏。
